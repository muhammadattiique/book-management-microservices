# Spring Core Architecture & Documentation: Book Service

This document outlines how Spring Framework's core principles—Inversion of Control (IoC), Dependency Injection (DI), component stereotypes, bean lifecycles, and layered separation—are implemented within the Book Service module.

---

## 1. Inversion of Control (IoC) & Dependency Injection (DI)

### Inversion of Control (IoC)
In a traditional application, your custom code is responsible for instantiating objects using the `new` keyword and managing their complete lifecycles. In our **Book Service**, IoC is inverted using the **Spring IoC Container**. The container is responsible for creating objects, wiring dependencies together, configuring them, and managing their entire lifecycle from startup to shutdown.

### Dependency Injection (DI) & Constructor Injection
Instead of classes manually looking up dependencies or instantiating services themselves, dependencies are *injected* into them by the Spring container.

Our application strictly enforces **Constructor Injection** using Lombok’s `@RequiredArgsConstructor`.

**Code Example (`BookServiceImpl.java`):**
```java
@Slf4j
@Service
@RequiredArgsConstructor
@Transactional
public class BookServiceImpl implements BookService {

    // Dependencies are declared as final, ensuring immutability and mandatory injection
    private final BookRepository bookRepository;
    private final AuthorRepository authorRepository;
    private final CategoryRepository categoryRepository;
    private final BookMapper bookMapper;

    // Spring automatically injects the required beans via the constructor generated by Lombok
}
